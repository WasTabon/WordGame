# WordGame — Итерация 13: Pan-управление полем

## Что исправлено

На больших уровнях (radius 5+) поле перестало помещаться в экран — буквы налезали друг на друга. Решение: **зафиксированный размер клеток** + возможность двигать поле пальцем/мышью.

### Размер клеток (новый)
- Level 1 (radius 2, 19 клеток): **75px** — поле помещается с запасом
- Level 2+ (radius 3+): **65px** — фиксировано, не уменьшается дальше
- На level 4+ поле выходит за экран → нужен pan

### Управление полем (одинаковое на PC и мобильнике)

**Кнопка `✥ MOVE`** в HUD рядом с кнопкой Back. Тап → переключает режим.

| Режим | Кнопка | Действие при свайпе/драге |
|---|---|---|
| **Word mode** (default) | серая, тёмная | составление слова (как раньше) |
| **Pan mode** | оранжевая, подсвечена | движение поля |

Тап на кнопку MOVE переключает между режимами. Слово составить в pan-режиме нельзя; двигать поле в word-режиме нельзя (через одиночный клик).

**Бонус для PC:** правый клик + drag двигает поле **в любом режиме** — естественный desktop-жест, не требует переключения.

### Auto-reset позиции
При запуске Game-сцены (новая партия, retry, next level) позиция grid сбрасывается на центр. Pan mode тоже сбрасывается в OFF.

### Clamp границ
Поле нельзя двигать слишком далеко — clamp с padding 100px. Видишь часть пустоты вокруг grid, но не «уплывает» совсем.

## Тестирование

| Сценарий | Ожидание |
|---|---|
| Level 1 (radius 2) | Поле маленькое, помещается. Pan можно использовать, но clamp почти 0 — поле почти не двигается |
| Level 2 (radius 3) | Поле помещается, можно слегка двигать |
| Level 4+ (radius 5+) | Поле выходит за экран. Тап `✥` → кнопка стала оранжевой → drag двигает поле |
| Слово в word mode | Свайп по буквам = составление слова. Поле НЕ двигается |
| Слово в pan mode | Тап на букву → ничего не происходит. Drag → двигает поле |
| Right-click + drag (на PC) | Поле двигается всегда, независимо от режима |
| Кнопка `✥` ещё раз | Снова word mode, серая |
| Restart / Next level | Поле центрируется обратно, pan mode OFF |
| BACK | Возврат в меню |

## Параметры

**`PanController`** в инспекторе:
- `Padding` = 100 — насколько за пределы Canvas можно «уплыть»
- `Right Mouse Drag Sensitivity` = 1 — множитель для right-click drag на PC

**`GameHUD`** новые поля:
- `Pan Off Color` / `Pan On Color` — цвета кнопки в выключенном/включённом состоянии
- `Pan Toggle Button` / `Pan Controller` — ссылки (Editor-скрипт прописывает)

**`LevelManager.GetCellSizeForLevel`** — формула:
```csharp
return level <= 1 ? 75f : 65f;
```
Поменяй если хочешь другой размер.

## Известные нюансы

- **Edge highlighter** (зелёный glow на границах в Escape) **двигается вместе с полем** — он у клеток внутри grid. Тебе видны подсвеченные клетки куда нужно прорываться, даже когда поле смещено.
- **FloatingScores** (всплывающее `+24`) **тоже двигаются** с полем — pan'нул поле сразу после слова, popup всё ещё над правильным местом.
- **Tutorial** в pan-режиме всё ещё работает (он перехватывает клики через overlay, неинтерактивные клетки в tutorial — норма).
- **Right-click на тач-экране** — не работает (right-click это desktop only). Мобильные игроки используют только кнопку.
- **Случайный тап мимо клетки** в word mode — ничего не делает (нет word, нет pan). Безопасно.
